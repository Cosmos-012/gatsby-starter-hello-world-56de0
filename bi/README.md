Analytics pipeline from operational ERP data to KPI dashboards
(executive, finance, sales, procurement, operations, projects) — see
`ROADMAP.md` Phase 9.

first, and reuses the KPI/dashboard pattern already proven in
`extensions/ecm-nuxeo-studio` (governance dashboard: cycle time, review
backlog, overdue reviews).
