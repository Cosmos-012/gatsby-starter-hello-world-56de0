# /source

Reference material on the existing Onfinity source code — notes,
extracted snippets under review, or (if licensing/access allows) a vendored
read-only copy used for the Phase 1 reverse-engineering pass.

in `/frontend`, `/backend`, and `/extensions`. This folder is strictly
about understanding the existing Onfinity core.
