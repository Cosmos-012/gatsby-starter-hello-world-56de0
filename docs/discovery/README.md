# Discovery output

Reports generated by `scripts/phase0-discovery.ps1` / `.sh` land here as
`<timestamp>-system-inventory.local.md`. These are **git-ignored by
default** (see root `.gitignore`) because they can capture host paths,
service names, and configuration values from the Onfinity/PostgreSQL host.

Before committing anything from this folder:

1. Open the report and remove/redact any password, connection string,
   token, or other secret.
2. Transcribe the reviewed findings into `docs/01-system-inventory.md`
   (the durable, reviewed record) rather than committing the raw report.
