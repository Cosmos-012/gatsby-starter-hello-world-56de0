# Extensions

Business and integration extensions that sit alongside the Onfinity core
(see `ARCHITECTURE.md` at the repo root for where this layer fits).

| Extension | Status | Description |
|---|---|---|
| [`ecm-nuxeo-studio/`](./ecm-nuxeo-studio) | MVP done | DocuCentral — controlled-document lifecycle management on Nuxeo, built on the Nuxeo Studio Community Cookbook. See `ecm-nuxeo-studio/docs/DOCUCENTRAL.md` for scope, content model, lifecycle, and roadmap, and `ecm-nuxeo-studio/docs/AUDIT.md` for the pre-MVP audit of the local setup it's built on. |

New extensions are added here as their own subdirectory once a phase in
`ROADMAP.md` actually requires them (e.g. a Sales, Procurement, or
Inventory extension once Phase 8 starts) — not created ahead of need.
