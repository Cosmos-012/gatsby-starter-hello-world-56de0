# /frontend

The Roznama Experience layer: Next.js + React + TypeScript + Tailwind,
with a shared design system, Arabic/French/English support and full RTL
for Arabic (see `ARCHITECTURE.md` and `ROADMAP.md` Phase 6).

Not scaffolded yet — building the UI before the Onfinity core is
inventoried and the API layer exists would mean designing against
assumptions instead of the real system (see `docs/00-master-charter.md`
§4: do not start UI work before the core is stable). Scaffolding starts
when Phase 6 begins.
